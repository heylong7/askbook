# Save Interview -- askbook 面试记录存档器

## 触发条件

用户输入 `/save-interview` 后立即执行，无需额外参数。

如当前对话中未检测到 `[QA_LOG]` 或面试问答标记，输出错误提示：
> 未检测到面试记录，请确认是否通过 /mock-interview 进行的面试。

---

## 执行流程（5 步）

```
Step 1: 对话提取   -> 从当前对话中提取 Q1~QN 边界，获取得分和题目
Step 2: 语义填充   -> 提取题目主干、候选人回答、标准答案要点
Step 3: 历史查询   -> 读取之前的 summary.tmp，构建成长曲线
Step 4: 生成双文件  -> 写入 summary.tmp + detail.tmp
Step 5: 展示确认   -> 输出路径和摘要，询问是否修正
```

---

## Step 1：对话提取

扫描当前对话历史，用正则或语义定位提取结构化字段：

```
锚点1 题目边界：Q{n}：{完整问题原文}
  提取：题号、题目全文

锚点2 回答：A{n}：{候选人回答原文}
  提取：回答全文（逐字保留，不摘要）

锚点3 得分：每题回答后给出的 X/10 分
  提取：精确分数

锚点4 方向：标记该题属于 项目综述 / 简历深挖 / 技术深挖
  提取：方向分类

锚点5 候选人信息：简历中提取的姓名或代号
  提取：候选人标识
```

---

## Step 2：语义填充

对每道题的对话区间，提取以下信息：

```
{
  "question": "面试官的完整提问，<=100字",
  "candidate_answer": "候选人回答原文，逐字记录，<=300字",
  "standard_answer": "面试官给出的参考答案核心要点，<=200字，保留关键术语和数字",
  "direction": "项目综述 | 简历深挖 | 技术深挖",
  "score": "得分/10",
  "score_reason": "为什么给这个分，缺少了什么，<=80字"
}
```

字段缺失处理：如无法提取某字段，填入 `"（未能提取）"` 占位，不留空。

---

## Step 3：历史记录查询

```
扫描路径：~/.claude/session-data/*mock-interview-askbook*-summary.tmp
过滤条件：type == "mock-interview-summary" AND candidate == 当前候选人
排序：按 date 升序

用途：
  - 构建成长曲线（历史各轮总分/平均分/强弱项数量）
  - 识别"突破项"：历史 need_retest:true，本轮 score >= 7
  - 识别"新弱点"：本轮首次出现的 score < 6 题目
  - 识别"退步项"：本轮比上轮同考察点低超过 2 分（如有）
```

无历史记录时：跳过成长曲线，标注"第 1 轮，暂无历史数据"。

---

## Step 4：生成双文件

### 文件命名规则

```
~/.claude/session-data/
├── YYYY-MM-DD-mock-interview-askbook-<candidate>-r<round>-summary.tmp
└── YYYY-MM-DD-mock-interview-askbook-<candidate>-r<round>-detail.tmp
```

- `<candidate>`：候选人姓名拼音首字母或用户提供的代号（如 `zhang`，无简历时用 `self`）
- `<round>`：历史 summary 文件数 + 1（如 `r3`）

---

### 摘要文件格式（`*-summary.tmp`，机器读）

```
---
type: mock-interview-summary
project: askbook
candidate: [姓名或代号]
date: YYYY-MM-DD
round: N
total_score: X
max_score: Y
avg_score: Z
---

questions:
  - id: Q1
    direction: [项目综述|简历深挖|技术深挖]
    topic: [考察点名称]
    score: X.X
    need_retest: true/false
  - id: Q2
    direction: [方向]
    topic: [考察点名称]
    score: X.X
    need_retest: true/false
  （每题一条，完整列出）
```

need_retest 判定规则：
- `score < 5` -> `need_retest: true`（必须重考，换角度提问）
- `5 <= score < 8` -> `need_retest: true`（建议重考，稍调整角度）
- `score >= 8` -> `need_retest: false`（可提难度后复用）

## Step 5：展示确认

生成完毕后输出：

```
摘要文件：~/.claude/session-data/YYYY-MM-DD-mock-interview-askbook-<ID>-summary.tmp
详情文件：~/.claude/session-data/YYYY-MM-DD-mock-interview-askbook-<ID>-detail.tmp

共提取 N 道题，总分 X/Y（Z.ZZ/10）
是否需要修正或补充？
```

如用户要求修正，更新对应字段后重新写入文件。

---

## 异常处理

| 情况 | 处理方式 |
|------|---------|
| 对话中无面试记录 | 输出错误："未检测到面试记录，请确认是否通过 /mock-interview 进行的面试" |
| 某题得分未匹配 | `score: null`，评分说明填"未能提取，请手动补充" |
| 候选人信息未识别 | candidate 使用 `self`，提示用户确认 |
| 历史 summary 文件不存在 | 跳过成长曲线，标注"第 1 轮，暂无历史数据" |
| 语义提取某字段为空 | 填入 `"（未能提取）"` 占位，不留空字段 |
